# Workflow: Research Report

**Trigger:** "Run the research workflow on <topic>"
**Output:** `output/<topic-slug>-report.md`, using `resources/report-template.md`

## Steps

### 1. Intake (before any research)
Ask the user, in one message:
- **Scope:** depth, time period, geography, what to include or exclude
- **Audience:** who the report is for and their knowledge level
- **Specific questions:** the exact things they want answered
- **Format and length:** target length and tone

Do not start researching until these are answered.

### 2. Plan checkpoint
Show a short plan:
- Sub-questions to research
- Source types to use
- Report outline

Wait for the user's OK. Adjust if they push back.

### 3. Research
- Web search each sub-question
- Prefer primary and recent sources
- Record the URL for every claim
- Flag conflicting or weak evidence

### 4. Organize
- Group findings by theme, not by source
- Drop anything that doesn't serve the user's questions

### 5. Write
- Fill in `resources/report-template.md`
- Bullets over paragraphs, plain language, no jargon
- End with Key takeaways and recommended next steps

### 6. Save and hand off
- Save to `output/<topic-slug>-report.md`
- Reply with a 3-bullet summary and note any gaps or low-confidence areas
